# DALIL logo (option A)

`DALIL_logo_option-A_original.svg` is the founders' file, unchanged. The others are cropped and recoloured copies for use:

| File | Use |
|---|---|
| `dalil-logo-stacked_dark` (.svg, @4x.png) | Full logo (mark, DALIL, دليل) on light backgrounds |
| `dalil-logo-stacked_light` | Full logo on dark backgrounds: the dark ink becomes bone white `#F2F1EC` |
| `dalil-mark_dark` / `dalil-mark_light` | The mark alone, for small placements (slide corners, favicons) |

Never put the mark on safety-yellow backgrounds: the yellow C disappears. Keep the yellow `#FFC700` as it is in every version.
