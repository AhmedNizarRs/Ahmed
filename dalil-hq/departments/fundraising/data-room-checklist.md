# Data room checklist

Keep a shared Google Drive folder named "DALIL Data Room". Tick when the latest version is in it.

## Company
- [ ] Trade licence and incorporation documents
- [ ] Cap table (who owns what)
- [ ] Founders' agreement (vesting, roles, IP assignment to the company)
- [ ] IP: design registration or patent filings

## Pitch
- [ ] Investor deck (latest version, PDF)
- [ ] One-pager (English and Arabic)
- [ ] The 15-second film and product photos
- [ ] Website: dalil-team.com

## Traction
- [ ] Pipeline summary (from `sales/pipeline.csv`)
- [ ] Letters of intent and pilot agreements
- [ ] User-testing summary (from `accessibility/`)
- [ ] Waitlist numbers

## Product
- [ ] Product spec summary (`product/product-spec.md`)
- [ ] Certification status and certificates (`product/certification-tracker.md`)
- [ ] Test results

## Financials
- [ ] Financial model (36 months)
- [ ] Unit economics (AED 18k per building, 58% margin: show the workings)
- [ ] Use of funds
- [ ] Bank statements (when asked, under NDA)

## Legal
- [ ] Template customer contract
- [ ] Any signed contracts
- [ ] NDA template
